# 해달타자

누구나 무료로 즐겁게 타자를 연습할 수 있는 한국어 타자 연습 웹 앱입니다.

## 실행하기

저장소의 `index.html`을 브라우저에서 열면 바로 사용할 수 있습니다. 설치나 계정이 필요하지 않습니다.

- 시작 화면에서 **연습 시작하기**를 누릅니다.
- **낱말 연습**은 낱말 50개, **장문 연습**은 문장 20개를 연습합니다.
- 화면의 글을 입력하고 Enter를 누릅니다. 틀리면 알림음과 흔들림으로 알려 주고, 모두 마치면 걸린 시간을 보여 줍니다.
