# wordRelay

친구들과 끝말잇기를 하며 Git과 GitHub를 배우는 협동 게임입니다.
단어 하나를 **Issue → 브랜치 → 커밋 → PR → 친구 리뷰 → Merge** 순서로 등록합니다.

## 첫 게임

- 시작 단어: **기러기**
- 게임 기록: [games/001.txt](games/001.txt)
- 다음 단어는 기록의 마지막 단어 끝 글자로 시작합니다. 시작 직후에는 **기**로 시작하는 단어를 제출합니다.
- 대장이 참가 순서를 정합니다. 머지된 단어만 인정하며 한 번에 한 사람씩 진행합니다.

## 참여 방법

1. 최신 `main`과 게임 기록을 확인하고 자기 차례를 기다립니다.
2. **Issues → New issue → 단어 제출**에서 이전 단어, 제안 단어, 사전 링크를 적습니다.
3. 최신 `main`에서 `word/<이슈번호>-<영문단어>` 브랜치를 만듭니다.
4. `games/001.txt` 끝에 단어 한 줄만 추가하고 커밋합니다.
5. `main`으로 PR을 열고 본문에 `Closes #<이슈번호>`를 작성합니다.
6. 친구의 리뷰와 승인을 받은 뒤 **Squash and merge**합니다.
7. 다음 참가자는 최신 `main`을 받아 이어갑니다.

세부 단어 규칙, 명령어 예시, 리뷰 기준은 [참여 규칙](CONTRIBUTING.md)을 읽어 주세요.

## 함께 달성할 목표

모두 단어 한 개 이상을 머지하고, 다른 사람의 PR을 한 번 이상 리뷰하면 첫 게임 성공입니다.
실수는 벌점 없이 같은 PR에서 고칩니다. 자동 검사 도입 전에는 친구가 연결 글자, 중복, 사전 등재 여부를 확인합니다.
